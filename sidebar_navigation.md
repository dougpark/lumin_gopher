# sidebar navigation

# modify dashboard.html and email.html to add a new sidebar 
- Add a left-hand sidebar to both dashboard.html and email.html for navigation.
- should be reusable on existing and future html pages to maintain consistency across the dashboard.
- A collapsible sidebar allows you to list dozens of pages while keeping the interface clean.
•	Categorization: Group your links by "Ingestion Streams," "System Tools," and "Archives."
•	Hierarchical View: You can use expandable menus so that "Ingestion" is a top-level category that expands to show Email Stats, Bluesky, Mastodon, Pinboard, Feedbin, Dayone, etc.
•	Icons: Use simple icons next to each link to visually differentiate them.

# Design Tip: 
- Since your dashboard uses a lot of "white space" and clean boxes. Use a dedicated left-hand sidebar with a "soft" background color (a slightly darker shade than your background) to separate navigation from data.
